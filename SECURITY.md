# Segurança e divulgação responsável

Esta versão é uma aplicação HTML estática para demonstração e homologação, não uma implantação corporativa multiusuário.

- Não introduza chamados reais, dados pessoais, credenciais, tokens, cookies, planilhas operacionais ou backups do navegador.
- O repositório e o site GitHub Pages são públicos. Revise qualquer arquivo antes de adicioná-lo.
- A aplicação não fornece backend, autenticação, autorização nem auditoria central.
- A política CSP atual bloqueia conexões de rede iniciadas pela aplicação; não remova essa proteção sem revisão de segurança.
